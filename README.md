# Juyeong Byeon

Product engineer building complex SaaS interfaces, AI workflows, and Web3 integrations with React and TypeScript.

I enjoy turning ambiguous product problems into maintainable software: interaction-heavy frontends, auditable internal workflows, and usable interfaces for complex technical systems.

## Selected work

- **[PatchPilot](https://github.com/Juyeong-Byeon/PatchPilot)** — A TypeScript workflow that turns approved tickets into policy-checked pull requests, with a Fastify API, BullMQ/Redis jobs, PostgreSQL, a React admin interface, CI, and mock end-to-end coverage.
- **[Symlesstalk](https://github.com/Juyeong-Byeon/symlesstalk)** — A read-only code-diagnosis prototype that returns `file:line` evidence, with strict TypeScript checks, tests, and security controls for prompt injection and filesystem boundaries.
- **[Cross-chain donation demo](https://github.com/Juyeong-Byeon/cross-chain-demo-donation)** — A Next.js prototype exploring XRPL, GemWallet, ethers, and EVM-sidechain flows.
- **[data-in-globe](https://github.com/Juyeong-Byeon/data-in-globe)** — A small React global-state library with dual-package builds, tests, and automated releases.
